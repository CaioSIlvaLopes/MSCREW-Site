# MSCREW - Crew Management

Site institucional One-Page para a MSCREW, empresa de recrutamento e gestão de tripulação marítima (Crew Management).

## Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Vanilla)
- JavaScript (Vanilla) para interações e scroll suave

## Estrutura
Projeto focado em performance (arquitetura estática), sem dependências externas.
